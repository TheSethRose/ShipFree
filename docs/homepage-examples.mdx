# Homepage Examples

## Overview

This folder contains **four complete alternate homepage patterns** built with the same ShipFree design system. Each example is a fully composed page using shared and category-specific components.

The production homepage at `/` is already the SaaS/starter-kit example. These examples cover other site types.

## Available examples

| Example | Best for | Route |
|---------|----------|-------|
| **Portfolio** | Designers, developers, creatives | `/examples/portfolio` |
| **Agency** | Creative studios, consultancies | `/examples/agency` |
| **Local Business** | Shops, restaurants, clinics | `/examples/local-business` |
| **Product** | Physical products, gadgets, launches | `/examples/product` |

## How to use one as your real homepage

1. Pick the example closest to your product.
2. Copy the imports and JSX from `src/app/examples/{type}/page.tsx` into `src/app/page.tsx`.
3. Keep or customize the related data file in `src/data/homepage-examples/{type}.ts`.
4. Delete unused example categories (see below).

## How to delete one category

Example: removing the portfolio example.

```bash
rm -rf src/app/examples/portfolio
rm -rf src/components/homepage-examples/portfolio
rm src/data/homepage-examples/portfolio.ts
```

Then remove the portfolio card from `src/app/examples/page.tsx`.

## How to delete all examples

```bash
rm -rf src/app/examples
rm -rf src/components/homepage-examples
rm -rf src/data/homepage-examples
rm docs/homepage-examples.mdx
```

No other files depend on these. The main homepage at `/` remains untouched.

## Component organization

### Shared components

Located in `src/components/homepage-examples/shared/`:

- `example-header.tsx` — Generic responsive header with nav and CTAs
- `example-footer.tsx` — Generic footer with link groups
- `example-section-header.tsx` — Reusable section title block
- `example-cta-section.tsx` — Final conversion CTA with card wrapper
- `example-feature-grid.tsx` — Feature/benefit card grid
- `example-proof-strip.tsx` — Stats/proof card strip
- `example-testimonials.tsx` — Testimonial grid
- `example-faq-section.tsx` — FAQ accordion section

### Category-specific components

**Portfolio:** `portfolio-hero`, `project-grid`, `skills-grid`, `experience-timeline`
**Agency:** `agency-hero`, `services-grid`, `process-section`, `results-section`
**Local Business:** `local-business-hero`, `service-area-section`, `hours-contact-section`, `review-grid`, `gallery-preview`
**Product:** `product-hero`, `product-showcase`, `license-section`, `product-pricing`

## Data files

Each example has its own data file in `src/data/homepage-examples/{type}.ts`. These are the single source of truth for content. Components accept data via props.

## Design guidance

- Use existing utilities from `globals.css`: `.section-padding`, `.section-kicker`, `.section-heading`, `.section-description`, `.marketing-card`, `.card-description`.
- Keep pages explicit. Do not convert this into a config-driven homepage builder.
- The design language is restrained: `bg-white` / `bg-[#F4F4F5]` alternation, `border-[#E4E4E7]`, `rounded-2xl` cards, monochrome palette.
